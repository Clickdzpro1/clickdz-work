## Engine 5.5 (powers CDZ Architect 5.5)
- spec: 1,050,000 token context window (approx. 922K input / 128K output split) · 128,000 max output tokens · text + image input, text-only output (audio/video not supported) · adjustable reasoning depth (none / low / medium / high / xhigh, default medium) · knowledge current to Dec 1, 2025
- powers:
  - Plans, executes, and verifies multi-part professional work end-to-end with minimal hand-holding
  - Frontier-tier agentic coding — state-of-the-art command-line workflow accuracy (82.7% on a leading terminal-automation benchmark) and real-world issue resolution (58.6% on a leading software-engineering benchmark)
  - Operates software directly: navigates interfaces, clicks, types, and moves across tools to finish a task
  - Produces long-form documents, spreadsheets, and slide decks from messy, unstructured business inputs
  - Sustains reasoning across scientific/technical research loops — forming hypotheses, gathering evidence, and deciding next steps
  - Matches the prior generation's response speed while delivering meaningfully higher intelligence and using fewer tokens per task
- blurb: This is the engine for work too complex to delegate to a shortcut — the one that holds an entire codebase, a messy spreadsheet, or a half-finished research plan in its head and simply finishes the job. It thinks harder, checks its own work, and gets there using less of your budget than the model it replaced.

## Engine 5.4 (powers CDZ Polyglot 5.4)
- spec: 1,050,000 token context window (272K standard window; extended context available, priced at 2x input / 1.5x output above 272K) · 128,000 max output tokens · text + image input, text-only output · adjustable reasoning depth (none / low / medium / high / xhigh, default none) · knowledge current to Aug 31, 2025
- powers:
  - First general-purpose engine with native, built-in computer operation — no external automation framework required
  - Plans, executes, and verifies tasks across long horizons using up to a million tokens of working context
  - Finds and calls the right tool out of huge tool libraries efficiently, without bogging down on irrelevant options
  - State-of-the-art desktop-navigation accuracy (75.0% success rate on a leading computer-use benchmark, surpassing typical human performance)
  - Persistent, multi-round web research that tracks down hard-to-find "needle in a haystack" information across many sources
  - Most token-efficient reasoning generation to date — solves the same problems using meaningfully fewer tokens than its predecessor, for faster and cheaper runs
- blurb: This is the engine built to actually run your software, not just talk about it — reading screenshots, clicking through interfaces, and carrying a task from first step to verified finish across an entire toolchain. It reasons for longer, remembers more, and gets more done per token than anything that came before it.

## Engine 5.4-mini
- spec: 400,000 token context window · 128,000 max output tokens · text + image input, text-only output · adjustable reasoning depth (none / low / medium / high / xhigh, default none) · knowledge current to Aug 31, 2025
- powers:
  - Runs coding, tool-calling, and computer-use tasks at roughly double the speed of the prior small-model generation
  - Approaches flagship-tier accuracy on demanding coding and desktop-navigation benchmarks at a fraction of the cost
  - Reads dense screenshots and user interfaces quickly enough for real-time, latency-sensitive computer-use work
  - Built to run as a subagent — handling narrow supporting tasks in parallel while a larger engine plans and coordinates
- blurb: The fast, economical sibling built for high-volume work — targeted code edits, quick tool calls, and screenshot-reading subagent tasks that need to feel instant. It gets most of the flagship's capability at a fraction of the latency and cost.
